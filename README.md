# Still

Une image, cadrée avec précision. Source intégrée ou ressource choisie, sans galerie ni diaporama.

Un add-on MyWallpaper autonome, sous licence MIT. Ses réglages sont ceux du manifeste. Il n'utilise aucun service privé du cœur, ne demande aucun accès natif et ne collecte aucune donnée. Les images externes restent des ressources réseau ; sans ressource choisie, une étude graphique originale incluse dans le dépôt est affichée.

Installez Node.js et pnpm, puis exécutez `pnpm install`, `pnpm build` et `pnpm test`. Avec le CLI MyWallpaper installé, lancez `mywallpaper dev` depuis ce répertoire et chargez son lien local dans les paramètres développeur de Desktop. Les modifications de fichiers produisent des révisions privées ; elles ne publient aucune version.

Pour distribuer : validez avec `mywallpaper check`, poussez ce dépôt public et un tag immuable `v0.1.0`, puis publiez cette version depuis MyWallpaper. Le build et l'admission sont assurés par l'autorité centrale de l'application.

La vignette montre le rendu réel ; les éléments de superposition sont présentés sur un fond de mise en scène qui n'est pas inclus dans l'add-on.
